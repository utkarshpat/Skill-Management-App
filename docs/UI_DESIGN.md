# Interface direction

The user prefers working on a laptop. All pages should be designed and reviewed on laptop screens first, while keeping phone layouts optimized and usable.

- Primary checks: 1366 × 768 and 1440 × 900 browser viewports; include shorter laptop windows.
- Laptop pages retain labelled navigation, useful working space and side-by-side content where appropriate. Avoid oversized landing-page spacing that pushes primary actions below the fold.
- Phone layouts stack content, keep actions readable and prevent horizontal page overflow. Wide data tables may use their own labelled scroll containers.
- Use the supplied Sopra Steria wordmark and mark, with orange/red accents, charcoal text and light surfaces.
- Show the actual workflow state; authentication, permission checks and employee data must not be simulated as working.
- Keyboard focus, readable labels and semantic structure apply to both layouts.

Current welcome and public workspace preview follow this direction. Remaining modules will be implemented one complete workflow at a time.
