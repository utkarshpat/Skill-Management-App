## Defects and corrections

### Private document previews blocked by hosted CSP

The hosted file APIs returned the authorized exact PDF bytes and worker assets loaded, but inline previews displayed “Preview could not be loaded.” The hosted CSP omitted `blob:` from `connect-src` and `img-src`; PDF.js reads authorized browser object URLs and image previews use them directly.

The correction in `apps/api/src/create-app.ts` adds `blob:` only to those required directives. `script-src` remains restricted; regression assertions reject Blob scripts, unsafe inline scripts and unsafe evaluation. The real `createApp` hosting response was exercised in a local browser: the same PDF rendered successfully with the application CSP. Screenshot: `.local/azure-pdf-csp-fixed-20261017.png`. This correction is now included in `acf9b39`, but the hosted browser still reproduced the old failure during this run. Deployment and a fresh hosted preview check are required.

### Person edit preview drops trusted capability projection

A hosted no-op preview for Khushi returned false personal-permission removals although the submitted person fields and assignments were unchanged. `LocalAccessStore.save`, used to simulate preview and recheck, reconstructed the person without the server-owned `business` projection. This also falsely trips the last-administrator guard when an administrator relies on an explicit System Admin responsibility.

The local correction in `apps/api/src/modules/access/local-access-store.ts` preserves a clone of the existing trusted projection. It never accepts replacement authority from the caller's person-edit payload. Regression coverage in `apps/api/test/effective-access.test.ts` first failed with the last-administrator error, then passed after the fix. It covers no-op impacts, baseline/Admin preservation, receipt recheck, ignored caller projection injection, deactivation behavior and unchanged source state. The ordinary API/SQL transaction still independently enforces current access. No hosted person/access save was performed in this run.
