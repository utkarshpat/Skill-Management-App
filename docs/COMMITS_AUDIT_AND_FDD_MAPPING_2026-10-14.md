## Most valuable next increment

Prioritize server-side **credential-wise distinct current approved holder reporting**, using canonical credential identity and the approved-renewal current-record projection. Add **full catalogue skill coverage including zero-holder skills** alongside it. Counts and ranking must be computed before pagination and match CSV/XLSX exports. These address concrete FDD reporting gaps without introducing more decorative charts or unsupported security dimensions.

Then add a genuine global top-certified ranking and certification-specific monthly achieved/current measures with clearly defined renewal and date semantics. Confirm canonical Practice/Pillar/Location source fields before implementing those dimensions. Monthly/lead/threshold notification policies can be specified next, while production scheduler activation stays aligned with the deferred company hosting.
